1. 할인 정책 개요

등촌 코인노래방은 주중(월~금) 18시 이전 입장 시 1시간당 500원 할인을 적용합니다. 할인은 자동 계산 시스템에 사전 설정해 두면 이용자 결제 단계에서 자동 차감되며, 별도 쿠폰 발행이 필요 없습니다.

주말(토·일) 및 공휴일에는 할인 적용이 제한되며, 연휴 전후 2일간은 할인율을 20% 내외로 낮추어 매출 변동성을 관리합니다. 이 정책은 지역 상권 분석 결과, 평일 오후 시간대에 이용객 흐름이 상대적으로 낮아 매출 보전 효과가 입증된 점을 근거로 설정되었습니다.

2. 할인 적용 방법 및 시스템 설정

할인 적용을 위해서는 POS 및 노래방 관리 시스템에 다음과 같은 변수값을 입력해야 합니다. :root { --discount-weekday: 500; --discount-weekend: 0; } 를 CSS 변수로 유지하면서, 백엔드 설정 파일에 discount_start: "06:00", discount_end: "18:00"을 지정합니다.

시스템 연동 시에는 API 호출을 통해 실시간 할인 여부를 검증합니다. 예를 들어, /api/discount-check?time=17:30 요청이 200 응답과 함께 { "discount": 500 } 를 반환하면 결제 화면에 자동 반영됩니다. 이 과정은 기존 코드 구조를 변경하지 않고, 기존 .r-card-xcyh 클래스를 그대로 활용해 UI 일관성을 유지합니다.

3. 인원 변동 대비 운영 팁

인원 변동이 큰 시간대(예: 18시~20시)에는 사전 예약 시스템을 활성화하고, 예약 취소 시 자동으로 할인 적용 여부를 재검토하는 로직을 도입합니다. 예약 시 reserve_time 필드에 할인 적용 가능 여부를 저장하고, 현장 도착 시 check-in 단계에서 재확인합니다.

또한, 인원 초과 시 대기실 관리와 동시에 할인 적용을 제한하는 옵션을 제공해 매출 손실을 최소화합니다. 이때 .m-item-yrtk 클래스가 적용된 대기 리스트 UI를 사용하면 디자인 일관성을 유지하면서도 직관적인 안내가 가능합니다.

4. 정산 체크리스트

가용 할인 금액과 실제 차감 금액이 일치하는지 확인하려면 일일 정산 파일에 discount_total 항목을 추가하고, 자동화 스크립트가 .x-btn-554l 버튼을 통해 CSV 형태로 추출하도록 설정합니다. 추출된 파일은 discount_report_YYYYMMDD.csv 형식으로 저장됩니다.

정산 단계에서 반드시 검증해야 할 포인트는 다음과 같습니다.
① 할인 적용 건수와 총 할인액
② 비할인 건수와 평균 결제 금액
③ 인원 변동 대비 할인 비율 변동 추이. 이 세 가지 지표를 모두 검토하면 할인 정책의 경제적 효과를 정량적으로 평가할 수 있습니다.

5. FAQ

Q1. 할인 적용 시 최소 이용 시간 제한이 있나요?

네, 할인이 적용되는 시간대에는 최소 30분 이용을 전제로 합니다. 30분 미만 이용 시 할인은 적용되지 않으며, 시스템 로그에 자동 차단 기록이 남습니다.

Q2. 할인은 멤버십 회원에게도 동일하게 적용되나요?

멤버십 포인트 적립은 할인 적용 전 금액을 기준으로 계산됩니다. 즉, 할인 후 결제 금액이 포인트 적립 기준을 초과하면 적립이 이루어집니다.

Q3. 할인 정책 변경 시 기존 예약에 어떻게 반영되나요?

정책이 변경되면 시스템은 기존 예약을 자동으로 재검증합니다. 재검증 결과 할인 적용이 불가능하면 알림 메시지가 전송되고, 고객은 추가 결제 또는 예약 취소 옵션을 선택할 수 있습니다.
